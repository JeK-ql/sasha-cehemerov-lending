# SEO/UX Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Виконати пакет SEO/UX-фіксів за спекою `docs/superpowers/specs/2026-07-14-seo-fixes-design.md`: хедер, футер C, title/meta/canonical, schema, security headers, LCP.

**Architecture:** Точкові правки існуючих компонентів Next.js App Router (Next 16.2.6). **Tech Stack:** Next.js 16.2.6 (App Router, Metadata API, next.config headers()), React 19 (`react-dom` `preload()`), vitest, sharp, ffmpeg.

### Task 7: next.config.ts — security headers

**Files:**

```ts
import type { NextConfig } from 'next';

/* CSP: дозволяємо тільки себе і WayForPay (script/frame/connect/form-action).
   'unsafe-inline' у script-src вимушений — Next.js інлайнить runtime-скрипти
   без nonce-інфраструктури; прибирати тільки разом із переходом на nonce. */
const csp = [
  "default-src 'self'",
  "script-src 'self' 'unsafe-inline' https://secure.wayforpay.com",
  "style-src 'self' 'unsafe-inline'",
  "img-src 'self' data: https:",
  "font-src 'self'",
  "connect-src 'self' https://secure.wayforpay.com https://api.wayforpay.com",
  "frame-src https://secure.wayforpay.com",
  "base-uri 'self'",
  "form-action 'self' https://secure.wayforpay.com",
].join('; ');

const securityHeaders = [
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
  { key: 'Permissions-Policy', value: 'camera=(), microphone=(), geolocation=()' },
  { key: 'Content-Security-Policy', value: csp },
];

const nextConfig: NextConfig = {
  async headers() {
    return [{ source: '/:path*', headers: securityHeaders }];
  },
};

export default nextConfig;
```
